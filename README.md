# CydraShield homepage

React + Vite homepage styled with Tailwind CSS v4. Motion is implemented with CSS keyframes and an Intersection Observer; the site respects reduced-motion preferences.

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite. To create a production build:

```bash
pnpm build
```

The deployable static site is written to `dist/`. The demo request form is currently a front-end prototype and needs a company inbox or form service before launch.
